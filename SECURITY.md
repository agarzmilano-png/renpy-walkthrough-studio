# Security policy

This beta processes local archives, compiled scripts, and game sources. Those
files are untrusted inputs. Work on copies and keep backups. The tool is not a
sandbox or an antivirus product. Container executable extraction is opt-in and
must not be used on untrusted executables.

For a vulnerability, use GitHub private vulnerability reporting **if enabled**.
Maintainers should enable it in repository Settings → Security before publishing.
If private reporting is unavailable, contact the maintainer privately through
their published profile; no reporting email is assumed here. Do not post exploit
payloads, credentials, complete games, saves, or sensitive paths in a public issue.

Public reproducible non-security bugs can use the bug-report form with a small
synthetic example. Include application version, platform, options, and sanitized
logs. No code-signing certificate or blanket security/compatibility guarantee is
provided by this source repository. Keep system protections enabled.
